# ERD-Diagrams
Entity Relationship Diagram (ERD) project designing a relational database, including entities, attributes, primary/foreign keys, and relationships between tables.
# ERD Project

## Overview
This project presents an Entity Relationship Diagram (ERD) designed. 
The goal is to organize the data in a clear structure and define how the entities relate to each other.

## What's Inside
- Entities and their attributes
- Primary keys and foreign keys
- Relationships and cardinality (one-to-one, one-to-many, many-to-many)
- Normalization to reduce data redundancy
